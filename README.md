make.fun bounty entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) — one original dad joke, at most 200 characters.

- `main.py` (pure Python standard library, no third-party packages)
  writes exactly one dad joke to `/output/entry.txt`.
- Deterministic: the joke is a constant, so two runs produce
  byte-identical output.
- The joke plays on "grounded": a cloud can never be grounded,
  because it is literally above all of that — a clean pun, told
  straight-faced, with the groan landing at the end.
